Notes on how this was put together

Rebuilt from a multi-part analytics export. Flow width uses a square-root scale so smaller paths stay visible next to the biggest ones — the exact visit count is always in the tooltip. Every branch traces automatically as far as its own traffic supports (not fixed to any set number of pages); to keep each section easy to scan, only a branch's top pages are shown individually, with smaller paths grouped into "Other pages" — the same rollup idea the analytics tool itself uses for its own long tail. "Other pages" isn't linked, since it's a rollup rather than one single page.
