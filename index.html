Notes on how this was put together

Rebuilt from a multi-part analytics export. Flow width uses a square-root scale so smaller paths stay visible next to the biggest ones — the exact visit count is always in the tooltip. To keep each section easy to scan, only the top pages in the three detailed sections (Collaborative Response, WeCollab, Resources) are shown individually; smaller paths are grouped into "Other pages," the same way the analytics tool groups its own long tail. "Other pages" isn't linked, since it's a rollup rather than one single page.
